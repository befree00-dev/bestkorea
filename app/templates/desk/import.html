1. 가져오기 버튼 등록 (처음 한 번)

아래 버튼을 브라우저 즐겨찾기(북마크) 막대로 끌어다 놓으세요. 즐겨찾기 막대가 안 보이면 Chrome·Edge는 ⌘+Shift+B(윈도우 Ctrl+Shift+B), Safari는 보기 메뉴 → 즐겨찾기 막대 보기. 예전에 등록한 Reddit 전용 버튼은 지우고 이 버튼으로 바꿔 주세요.

BestKorea로 가져오기

이 버튼에는 이 사이트 주소({{ origin }})가 들어 있습니다. 사이트 주소가 바뀌면 다시 등록하세요.

2. 사용법

사이트어디서 누르나참고
Reddit게시글 페이지 (reddit.com/r/…/comments/…)바로 가져옵니다
YouTube영상 페이지 (youtube.com/watch?v=…)댓글을 불러오려고 화면이 자동으로 내려갑니다 (최대 45초). 쇼츠는 지원하지 않습니다
X게시물 페이지 (x.com/아이디/status/…)로그인해야 답글이 보입니다. 화면을 자동으로 내리고 '답글 더 보기'도 눌러 가며 불러옵니다 (최대 45초)

버튼을 누르면 새 탭에서 이 페이지가 열리고, 데이터를 다 읽으면 수집함에 자동으로 추가됩니다. 팝업이 차단되면 이 사이트의 팝업을 허용하세요. 읽는 동안 원래 페이지 오른쪽 위에 진행 상황이 표시됩니다.

자동으로 안 될 때: 붙여넣기

새 탭으로 전달이 안 되면 원래 페이지 오른쪽 위에 데이터 복사 버튼이 나타납니다. 누른 뒤 아래 칸에 붙여넣기(⌘V) 하고 추가를 누르세요. Reddit은 글 주소 끝에 .json을 붙여 연 뒤 전체 내용을 복사해 붙여넣어도 됩니다.
