# BestKorea

해외 각 지역(북미·일본·중국·동남아·유럽·남미·호주·아프리카)의 언론과 커뮤니티의 한국 관련 뉴스와 현지인 반응을 소개하는 뉴스/커뮤니티 사이트입니다.
**모든 게시물은 사람이 직접 올립니다.** 운영자가 Reddit·YouTube·X에서 고른 글을 브라우저 버튼으로 관리자·운영자 전용 '수집함'에 가져오고, 번역 버튼으로 본문과 댓글을 번역한 뒤 다듬어 게시합니다. 자동 수집은 하지 않습니다.

## 회원 등급

| 등급 | 해외 반응 게시판 | 커뮤니티 게시판 | 수집함 | 관리 |
|---|---|---|---|---|
| 관리자 (1명) | 작성 | 작성 | 사용 | 회원 등급 지정, 기자 지원 승인, 이용 제한, 모든 글 삭제 |
| 운영자 | 작성 | 작성 | 사용 | - |
| 기자 | 작성 | 작성 | - | - |
| 회원 | - (기자 지원 가능) | 작성 | - | - |
| 비회원 | 읽기 | 읽기 | - | - |

- 관리자: `ADMIN_EMAIL`로 가입한 회원 (비우면 첫 가입자). 관리자 넘기기는 서버에서 `flask make-admin 이메일` (기존 관리자는 운영자가 됨)
- 운영자: 관리자 페이지 → 회원 등급 관리에서 지정
- 기자: 회원이 해외 반응 게시판의 **기자 지원하기**로 지원 → 관리자 페이지에서 승인

## 기능

| 구분 | 내용 |
|---|---|
| 해외 반응 게시판 | 정치 / 경제 / 연예 / 스포츠 / 게임 / IT / 사회 / 기타 (출처 지역 필터: 북미·일본·중국·동남아·유럽·남미·호주·아프리카, 최신·추천순, 검색), 원문 링크·대표 이미지·현지 반응(번역 댓글) |
| 커뮤니티 | 유머게시판, 자유게시판 |
| 수집함 (관리자·운영자) | 운영자가 Reddit·YouTube·X 게시물 페이지에서 **BestKorea로 가져오기** 버튼(북마클릿)을 누르면 글·댓글을 브라우저가 읽어 수집함에 추가 (댓글 10개 이상, 인기 댓글 최대 50개). API 키 불필요, 서버는 각 사이트에 접속하지 않음. 상태·사이트·댓글순 필터 |
| 번역 버튼 | 글 상단·하단. 원문(기사·게시물 본문 또는 영상 설명)과 대표 이미지를 가져와 Claude로 **본문 전체 번역**(문단 유지), **댓글 전체 번역**(하단 배치, 번역문만 표시), 카테고리 추천 → **게시판에 올리기**를 누르면 번역 내용이 채워진 글쓰기 화면으로 이동 (번역 전에도 누를 수 있으며, 이 경우 원문이 채워짐) |
| 수익화 | Google AdSense 슬롯 4곳, `ads.txt` 자동 생성, 개인정보처리방침(쿠키·광고 고지) |
| SEO | 페이지별 title/description/OG 태그, canonical, `sitemap.xml`, `robots.txt` |
| 본문 이미지 | 글쓰기에서 **이미지 넣기** 버튼·끌어다 놓기·붙여넣기(⌘V)로 업로드 → 본문에 `![](/uploads/…)` 한 줄로 들어가고 게시글에서 그림으로 표시, **미리보기** 지원. JPG·PNG·GIF·WEBP, 10MB 이하(`MAX_IMAGE_MB`), 위치정보 등 메타데이터 제거·큰 이미지는 긴 변 2000px로 축소. Docker 에서는 `uploads` 볼륨에 보존 |
| 보안 | 비밀번호 해시, CSRF, 사용자 HTML 미허용, 오픈 리다이렉트 차단, 원문 가져오기 시 내부망 주소 차단 |

## 카테고리와 출처 지역

- 카테고리: 정치, 경제, 연예, 스포츠, 게임, IT, 사회, 기타 (`app/constants.py`의 `BOARDS`)
- 출처 지역: 북미, 일본, 중국, 동남아, 유럽, 남미, 호주, 아프리카 (`COUNTRIES`)
  - 가져올 때 X 게시물 언어로 추정(일본어→일본 등, 영어·스페인어처럼 여러 지역에서 쓰는 언어는 추정 안 함)
  - 번역할 때 지역을 모르면 Claude가 채널·계정·내용으로 추정
  - 글쓰기 화면에서 운영자가 최종 선택
- 플랫폼(Reddit·YouTube·X)은 지역과 별도로 수집함에 표시됩니다
- 예전 데이터: 서버 시작 시 '미국'은 '북미'로, 플랫폼으로 저장돼 있던 국가는 '지역 미지정'으로 자동 변경. 예전 '정치·사회' 글은 '정치'에 남으므로 사회 글은 글 수정에서 옮기세요

## 운영 흐름

1. 운영자가 Reddit·YouTube·X에서 글을 보다가 즐겨찾기 막대의 **BestKorea로 가져오기**를 누르면 **수집함**에 추가됨 (사이트에는 게시되지 않음)
2. 운영자가 수집함에서 글을 열고 **번역** 클릭 → 수십 초~몇 분 뒤 한국어 제목, 본문 번역, 이미지, 번역 댓글 표시
3. **게시판에 올리기** → 제목·번역문·원문 링크·이미지·카테고리가 채워진 글쓰기 화면에서 다듬어 등록
4. 번역된 댓글은 글쓰기 화면의 **현지 반응** 편집 칸에서 고치거나 빼거나 직접 추가한 뒤 게시글과 함께 올라가고, 수집함 글은 '게시됨'으로 바뀜 (게시 후에도 글 수정에서 편집 가능)

## 빠른 시작

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env        # SECRET_KEY 등 수정
FLASK_APP=wsgi .venv/bin/flask run
```

- http://localhost:5000 접속 → `ADMIN_EMAIL`(비우면 첫 가입자)로 가입한 회원이 관리자가 됩니다.
- 화면 확인용 샘플 데이터: `FLASK_APP=wsgi .venv/bin/flask seed-demo` — 운영자·기자·회원 샘플 계정(비밀번호 `demo12345`)과 수집함 샘플이 생깁니다. 운영 DB에는 사용하지 마세요.
- 등급 변경(CLI): `flask set-role 이메일 operator|reporter|member`, 관리자 넘기기: `flask make-admin 이메일`
- 테스트: `.venv/bin/python -m pytest -q`

## 브라우저에서 가져오기

수집함 → **브라우저에서 가져오기**에서 **BestKorea로 가져오기** 버튼을 브라우저 즐겨찾기 막대로 끌어다 놓으면 준비 끝입니다.

| 사이트 | 어디서 누르나 | 읽는 방법 |
|---|---|---|
| Reddit | 게시글 페이지 | 글 주소 + `.json` (운영자 브라우저에서 요청) |
| YouTube | 영상 페이지 (`youtube.com/watch?v=…`, 쇼츠 제외) | 페이지의 영상 정보 + 화면을 자동으로 내리며 불러온 댓글 (최대 45초) |
| X | 게시물 페이지 (`x.com/아이디/status/…`, 로그인 필요) | 화면의 게시물 + 자동으로 내리고 '답글 더 보기'를 눌러 가며 불러온 답글 ('더 찾아보기' 등 다른 섹션 제외, 최대 45초) |

- Reddit: 버튼을 누르면 새 탭으로 가져오기 페이지가 열리고 바로 수집함에 저장됩니다.
- YouTube·X: 버튼을 누르면 그 탭에서 화면을 내리며 댓글을 읽습니다. **다 읽을 때까지 그 탭을 보고 있어야** 합니다 (탭이 가려지면 브라우저가 화면 갱신을 멈춰 댓글이 더 불러와지지 않음). 다 읽으면 나오는 **수집함으로 보내기**를 누르면 새 탭에서 저장됩니다.
- 팝업이 차단되면 허용하세요. 가져온 뒤 안내에 버튼 버전·읽은 댓글 수·멈춘 이유가 표시됩니다.
- 새 탭으로 전달이 안 되면 원래 페이지 오른쪽 위의 **데이터 복사** 버튼을 눌러 가져오기 페이지에 붙여넣습니다.
- 버튼에는 사이트 주소가 들어 있으므로 도메인이 바뀌면 다시 등록합니다.
- YouTube·X는 화면 구조를 읽는 방식이라 사이트 개편 시 동작이 멈출 수 있습니다. 그때는 `app/templates/desk/_grabber.js`의 선택자를 고칩니다.
- 브라우저에서 읽은 값은 서버에서 다시 검증합니다 (주소는 ID로 다시 만들고, 이미지는 각 사이트 이미지 서버만 허용, 댓글 수 기준 확인).

## Docker로 실행 (웹 + PostgreSQL)

Docker Desktop(또는 Docker Engine + Compose)만 있으면 됩니다.

```bash
cp .env.example .env              # ADMIN_EMAIL 등 필요한 값만 수정 (없어도 실행됨)
docker compose up -d --build      # http://localhost:8000
```

| 컨테이너 | 역할 |
|---|---|
| `web` | gunicorn 웹 서버 (포트 8000, `WEB_PORT`로 변경) |
| `db` | PostgreSQL 16, 데이터는 `pgdata` 볼륨에 보존 |

자주 쓰는 명령:

```bash
docker compose exec web flask seed-demo          # 샘플 데이터 (테스트용)
docker compose exec web flask make-admin 이메일    # 관리자 넘기기
docker compose exec web flask set-role 이메일 operator   # 운영자 지정
docker compose down                              # 중지 (데이터 유지)
docker compose down -v                           # 중지 + DB 데이터 삭제
```

`.env`에서 `ADMIN_EMAIL`을 지정하면 그 이메일로 가입한 회원만 관리자가 됩니다 (비우면 첫 가입자).
`docker-compose.yml`의 DB 비밀번호는 로컬 테스트용이므로 인터넷에 공개하는 서버에서는 바꾸세요.

## 직접 서버 운영 예시

```bash
.venv/bin/gunicorn -w 3 -b 127.0.0.1:8000 wsgi:app
```

Nginx 등으로 HTTPS 리버스 프록시를 두고 `SESSION_COOKIE_SECURE=true`, `SITE_URL`을 실제 도메인으로 설정하세요. 트래픽이 늘면 `DATABASE_URL`을 PostgreSQL로 바꾸면 됩니다 (`psycopg[binary]` 설치).

## Google AdSense 연결

1. 사이트를 공개 도메인에 배포하고 콘텐츠가 어느 정도 쌓인 뒤 AdSense 신청
2. 승인 후 `.env`에 `ADSENSE_CLIENT=ca-pub-…`와 광고 단위별 슬롯 ID 입력, `SHOW_AD_PLACEHOLDERS=false`
3. `https://도메인/ads.txt`가 자동으로 제공됩니다
4. `/privacy`, `/terms` 페이지의 운영자 연락처 등을 실제 정보로 수정하세요 (AdSense 심사에 필요)

## 번역 버튼 설정 (Claude API)

`.env`에 `ANTHROPIC_API_KEY=…`를 넣으면 수집함의 **번역** 버튼이 동작합니다. 키가 없으면 버튼을 눌렀을 때 오류 안내가 표시됩니다.

- 1회 클릭 = Claude 호출 1회 (제목 + 본문 전체 + 카테고리 + 댓글 전체 번역을 한 번에, 구조화된 JSON 출력)
- 기본 모델 `claude-opus-5-5`, effort `low`. 비용을 줄이려면 `ANTHROPIC_MODEL=claude-haiku-5-5`
- 원문 본문을 못 가져오면(유료벽, 차단 등) 수집된 내용만 번역하고 화면에 그 사실을 표시합니다
- 본문 전체를 번역하므로 긴 기사는 비용이 커집니다 (Opus 기준 긴 기사 1건 수십 센트). 비용을 줄이려면 `ANTHROPIC_MODEL=claude-haiku-5-5`
- 번역할 본문 최대 길이 `ARTICLE_MAX_CHARS`(기본 60,000자), 댓글 수 `COMMENTS_PER_ITEM`(기본 50)

## 저작권·이용 정책 관련 주의

- **번역 버튼은 원문 본문 전체를 번역합니다.** 언론사 기사의 전문 번역을 그대로 게시하면 원저작자의 번역권 침해가 될 수 있으므로, 기사 원문을 번역한 경우 수집함 화면에 경고가 표시됩니다. 게시 전에 인용 범위로 줄이고 출처·원문 링크를 반드시 남기세요. YouTube 설명·SNS 게시물·댓글도 작성자에게 권리가 있으니 출처(작성자)를 표시하세요.
- 원문 기사의 대표 이미지는 저작권이 원 매체에 있습니다. 게시 전에 사용 가능 여부를 확인하세요 (글쓰기 화면에서 이미지 주소를 지울 수 있습니다).
- X 데이터는 X 개발자 약관을 따릅니다. 게시물을 소개할 때 원문 링크와 작성자(@아이디)를 함께 표시하세요.
- YouTube 데이터는 YouTube API 서비스 약관을 따릅니다. 게시글에는 영상을 YouTube 공식 플레이어로 삽입하고 원문 링크를 함께 싣습니다. 댓글은 작성자 닉네임과 함께 번역해 소개하며, 요청 시 삭제할 수 있도록 운영하세요.

## 구조

```
app/
  __init__.py        앱 팩토리, 템플릿 필터, 에러 페이지
  constants.py       게시판·국가·회원 등급 정의, 게시 권한
  models.py          User(등급), ReporterApplication, Post, Reaction(현지 반응), Comment, Like, CollectedItem(수집함)
  views.py           목록/상세/글쓰기(수집함에서 작성 포함)/댓글/추천, 기자 지원, sitemap·robots·ads.txt
  desk.py            수집함 (관리자·운영자): 목록, 상세, 번역 버튼, 숨기기, 브라우저에서 가져오기
  admin.py           관리자: 등급 관리, 기자 지원 승인
  auth.py            회원가입·로그인
  collector/         browser_import.py(가져온 데이터 검증), fetchers.py(공통), classify.py(분류),
                     translate.py(원문 추출 + Claude 번역)
  templates/desk/_grabber.js   'BestKorea로 가져오기' 버튼 코드 (Reddit·YouTube·X 페이지에서 실행)
  cli.py templates/ static/
tests/               권한·수집·번역 테스트 (네트워크 없이 모의 응답 사용)
```
